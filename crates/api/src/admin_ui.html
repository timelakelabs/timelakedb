Configuration

Provenance is the layout: each setting shows its effective value and the layer it resolved from (default < property < override). Reverting an override falls back to the property, not the default. A change is validated as a whole — gc_grace_secs must exceed query_timeout_secs — and refused with the reason if it would break. A hot setting applies at once; staged/boot apply on the next restart. 🔒 marks a setting pinned by a system property.

Set a policy

Shrinking a window deletes data. A policy takes effect on the next enforcement pass (≤ 60 s) and drops become permanent once the GC grace elapses. Growing a window needs operator; shrinking, introducing, or removing one needs admin.

Data-plane tokens

DescriptionScopeDatabasesGrantsStatus

Issue a token

The secret is shown once, right here — only its digest is stored, so there is no way to see it again. Paste it into the client now (Grafana's token field; Telegraf v2 token; Telegraf v1 password) or revoke it and issue another. Granted authorizations intersect a caller's claimed SEC-2 labels — a token can only narrow what its holder sees, never widen it. Issuing and revoking need admin.

Audit trail

Time (UTC)ActorActionTargetOutcome
The chain is tamper-evident, verified on every load (?verify=1): a hand-edited record breaks it at its sequence number, shown above. A denied or rejected action is recorded too — that is the point of the trail. While the audit sink is unavailable every mutation is refused (503, fail-closed), so a change can never land unrecorded; TIMELAKE_AUDIT_FAIL_OPEN is the loud opt-out.
